
# Road Network Lab

Exploring, modeling, and analyzing transportation networks through mathematics, graph theory, and computational tools.

## Objectives

- Represent road systems as graphs.
- Analyze intersections, connections, and route structures.
- Implement shortest-path algorithms such as Dijkstra's and A*.
- Study highway concurrencies and network connectivity.
- Investigate network resilience under road closures.
- Visualize real-world transportation networks.

## Technologies

- Python
- NetworkX
- OSMnx
- GeoPandas
- Matplotlib
- Folium

## Project Status

Currently setting up the project and exploring road network data.

## Motivation

I've been fascinated by transportation networks, highway systems, route numbering, and geographic connectivity for as long as I can remember. This project is an opportunity to explore those interests through computer science and applied mathematics.
